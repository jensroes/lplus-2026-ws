# Data Preprocessing With RStudio And The Tidyverse

This folder contains the workshop materials.

## Start here

1. Open `lplus-2026-ws.Rproj` in RStudio.
2. Open the scripts in `exercises/`.
3. The example data are in `data/`.

## Data files

- `data/chinese_ldt.csv`
- `data/chinese_ldt.xlsx`
- `data/chinese_ldt.sav`

These contain the same example dataset in CSV, Excel, and SPSS formats.
