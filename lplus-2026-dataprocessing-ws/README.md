# Data Preprocessing With RStudio And The Tidyverse

This folder contains the workshop materials.

## Start here

1. Open `lplus-2026-dataprocessing-ws.Rproj` in RStudio.
2. Open the scripts in `exercises/`.
3. The example data are in `data/`.

## Data files

Live workshop data:

- `data/chinese_ldt.csv`
- `data/chinese_ldt.xlsx`
- `data/chinese_ldt.sav`

These contain the same example dataset in CSV, Excel, and SPSS formats.

Follow-up practice data:

- `data/blomkvist.csv`
- `data/blomkvist.xlsx`
- `data/blomkvist.sav`

## Exercise files

- `exercises/01_reading_inspecting.R`
- `exercises/02_select_filter_mutate.R`
- `exercises/03_summarise_by.R`
- `exercises/04_integrated_live_exercise.R`
- `exercises/05_optional_pivoting_backup.R`
- `exercises/06_followup_blomkvist.R`

Exercises 01-04 are for the live workshop. Exercise 05 is optional backup material on pivoting. Exercise 06 is follow-up practice with a new dataset.
